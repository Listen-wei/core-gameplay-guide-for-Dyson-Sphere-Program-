# 戴森球计划产线规划器

一个无需安装依赖、可以直接在浏览器运行的《戴森球计划》生产规划工具。项目同时包含递进式新存档攻略、模块化施工图册和蓝图覆盖审计。

## 功能

### 单条产线与全链路计算

- 内置 184 条《戴森球计划》BWIKI 配方，页面运行时不需要联网。
- 支持按指定产量或传送带满载计算。
- 精确设备数量显示到小数点后两位，同时给出实际向上取整数量。
- 支持制造台、熔炉、化工厂、精炼厂、对撞机、研究站等不同设备速度。
- 支持三档传送带、1–4 倍堆叠、增产和生产加速。
- 自动递归展开完整生产链，汇总外部资源、全部设备和副产物。
- 同一产物有多个配方时，可以在流程图节点中自由切换路线。
- 可在流程图内切换中间产物设备，并标记各节点的完成状态。
- 支持等离子精炼的“保留全部产物”“只要精炼油”“只要氢”三种处理模式。
- 支持创建、保存和删除浏览器本地自定义配方。

### 攻略与施工图

- 从落地到白糖 120/min 的递进式施工工单。
- 每一步给出目标产速、精确设备数、直接输入、库存目标和验收条件。
- 28 张交互施工模板：8 张严格递进主线图 + 20 张通用模块图，覆盖黑雾开局、总线超市、采矿、冶炼、制造、化工、科研、戴森球、物流和供电。
- 自动检测全部配方是否存在对应施工图。
- 提供白糖 120/min、太阳帆 120/min、火箭 10/min 同时运行的终局需求模拟。

## 快速开始

项目没有第三方运行依赖。克隆后可以直接打开 `index.html`，也可以启动本地静态服务器：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 使用方法

1. 搜索并选择目标配方。
2. 选择生产设备、增产方案和传送带等级。
3. 选择“按满带计算”或填写目标产量。
4. 查看精确设备数、实际建造数和各条输入/输出带的瓶颈。
5. 在全链路流程图中为存在替代路线的产物选择配方。
6. 按流程图从原料端向目标产物端逐项建设并标记完成。

自定义配方和流程图完成状态保存在浏览器 `localStorage`，不会上传到服务器。

## 开发与校验

需要 Node.js 20 或更高版本。

```bash
npm run check
npm test
npm run audit:blueprints
npm run audit:layouts
npm run simulate:late-game
```

一次执行全部本地校验：

```bash
npm run validate
```

## 更新配方数据

配方数据静态保存在 `wiki-recipes.js`。需要从 BWIKI 更新时运行：

```bash
npm run import:wiki
```

该命令需要网络连接，并会覆盖当前的 `wiki-recipes.js`。更新后应重新执行 `npm run validate`，确认配方结构、产线计算和施工图覆盖没有退化。

当前数据来源记录在 `wiki-recipes.js` 顶部，包括来源页面、修订号、来源修订日期和导入时间。请注意：导入日期不代表配方已更新到同一天；当前来源修订日期为 2023-12-21。若游戏内数值不同，以游戏内为准并先更新数据或在计算器中手动校正。

## 计算口径

- 所有速率默认使用“个/分钟”。
- 精确设备数用于产线配平；游戏内实际建设数始终向上取整。
- 全链路副产物会单独汇总，但默认不跨分支自动抵扣，因此需求结果偏保守。
- 采矿、抽水、抽油和轨道采集受资源与科技影响，流程图将它们视为外部输入。
- 攻略中的基础方案默认无增产剂，后期可在计算器中切换增产或加速重新配平。
